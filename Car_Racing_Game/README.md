This is a fun little "game" I made in 8th grade, with shapes2, a 2D drawing library that my teacher gave me. 

The game does all the trigonometry and 3D calculations itself, and updates the GUI using 2D methods from shapes2. (This project was instrumental in helping me learn trigonometry.)

To move, use WASD. The line coming out of the front of the car represents the wheel angle, so the more it's tilted, the more the car will turn.
